# Intro to Sewing Class Syllabus

> **Work in progress.** This is a draft syllabus for the Intro to Sewing class and is still being developed.

## Overview

**Class goals:** Familiarize users with the sewing machines and how to wind a bobbin, thread a machine, select stitches, and know when to use different stitches to mend or perform small alterations to their garments. This class will *not* cover reading patterns or making clothing.

See also the [Sewing Machine](TOOLS/FIBER-ARTS/sewing-machine.md) tool page.

## Tools to Get Started
- Machine
- Machine's pedal
- Needle and thread
- Fabric scissors
- Thread scissors
- Fabric
- Pins / clips
- Chalk
- Space

## Machine Basics
- Top-load vs side-load bobbins
- Where to wind a bobbin
- Using the handwheel
- Tensioner, seam selector, width selector
- How to thread a machine
- Pedal control
- Presser foot
- Seam guide (seam allowance)
- How to select the correct thread
- How to select the correct needle
- Sizing notation

### Demonstration
- Checking and cleaning your machine
- Winding a bobbin
- Threading a needle

## Stitch Basics
- Straight vs zigzag vs decorative
- Stitch length
- Backstitch
- Seam allowance

### Demonstration
- Each stitch
- Example of over- and under-tension
- Moving the piece
- Turning a corner

## Stitch Practice
- Corners
- Spiral
- Shape

## Fabric Basics
- Preparing fabric
- Types of fabric
- Types of thread (e.g. polyester)

## Double Hem Demonstration

Show how to iron and pin and the importance of seam allowance.

There will be a backup at the ironing station, so it may be helpful to have several irons or to prepare swatches in advance and have people practice ironing when they finish sewing (to prepare the swatches for the next class).

Reference video: [How to Sew | Double Hem (Beginner's tutorial)](https://www.youtube.com/watch?v=IW9I5jQZfyg&t=5s&ab_channel=LoveCrafts)

## Final Discussion

### Common Fixes
- **Hard:** Zippers, some alterations, stretchy fabrics
- **Medium:** Taking in some garments, hemming
- **Easy:** Patches
