# Raspberry Pi 101: Turning your Pi into a server

This is for anybody interested in learning how to run a Raspberry Pi as a server and access it from anywhere in the world. No prior experience with Linux or the Raspberry Pi is necessary.

What we cover:

  -  Flashing a Raspberry Pi operating system (Raspbian) onto an SD card
  -  Connecting your Pi to a local network
  -  Wirelessly connecting to your Pi from your laptop
  -  Tips for navigating the Linux command line
  -  Public/private key authentication for SSH
  -  Accessing your Pi from outside your home network
