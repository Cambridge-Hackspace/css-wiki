## Best Practices
- Always cut away from yourself
- Always wear safety glasses
- Turn on the dust collection system and air filter system see
- Secure workpiece before cutting
- Use sharp tools (dull tools are dangerous)
- Check for nails/screws before cutting
- Plan cuts before making them
- Clean up sawdust regularly
