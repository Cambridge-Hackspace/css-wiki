# Member Tools You Can Borrow

## Overview
Personal tools that members have generously made available for fellow members to borrow for projects.

## Borrowing Guidelines
- **Sign out tools** using the checkout system
- Return tools **clean and in good condition**
- Return by agreed-upon date
- Report any damage immediately
- Respect tool owners' conditions
- Replace consumables used (blades, sandpaper, etc.)

## How to Borrow
1. Check available tool list
2. Contact tool owner or workshop coordinator
3. Sign checkout sheet with:
   - Your name and contact info
   - Tool description
   - Date borrowed
   - Expected return date
4. Return tool and sign back in

## Available Tools
*Current inventory to be maintained by workshop coordinator*

Examples may include:
- Specialty hand tools
- Power tools
- Measuring instruments
- Clamps and fixtures
- Specialty bits and accessories

## Lending Your Tools
Interested in sharing your tools with other members?
- Contact workshop coordinator
- Label your tools clearly
- Set any usage conditions
- Specify replacement requirements

## Responsibilities
### Borrower
- Treat tools as if they were your own (or better!)
- Use tools safely and appropriately
- Clean before returning
- Report damage honestly
- Return on time

### Lender
- Ensure tools are safe to use
- Provide basic usage instructions if needed
- Be reasonable with lending terms
- Communicate clearly about expectations

## Lost or Damaged Tools
- Report immediately to workshop coordinator
- Work with tool owner to repair or replace
- Be honest about what happened
- Take responsibility
