# Multimeters

## Overview
Electronic test equipment for measuring voltage, current, resistance, and other electrical properties.

## Available Equipment
- We have about 20 of them, thanks to the innovation institute!

## Common Measurements

### Voltage (V)
- **DC Voltage**: Batteries, power supplies, logic circuits
- **AC Voltage**: Mains power (use caution!)
- Red probe to positive, black to negative/ground

### Current (A)
- Must be connected **in series** with load
- Start with highest range
- Be aware of meter's current limits
- Use appropriate fuse rating

### Resistance (Ω)
- Circuit must be **powered off**
- Discharge capacitors first
- Useful for testing continuity
- Testing resistor values

### Continuity
- Tests if circuit is complete
- Beeps when resistance is very low
- Useful for checking wires, traces, switches

## Safety Guidelines
- **Never measure AC mains voltage without proper training**
- Start measurements on highest range
- Check meter settings before connecting
- Discharge capacitors before testing
- Don't exceed meter's voltage/current ratings
- Check probe condition before use
- Use proper CAT-rated meter for mains work

## Using a Multimeter
1. Select the function (V, A, Ω, etc.)
2. Select AC or DC if applicable
3. Choose appropriate range (or use auto-range)
4. Connect black probe to COM
5. Connect red probe to appropriate jack
6. Take measurement
7. Record reading

## Maintenance
- Check battery level
- Inspect probes for damage
- Verify calibration periodically
- Replace fuses if blown
- Report any issues to workshop staff

## Common Mistakes to Avoid
- Measuring current in parallel (will blow fuse)
- Measuring resistance on powered circuit
- Exceeding voltage/current ratings
- Using damaged probes
- Wrong setting for measurement type
