# Knitting Machines

## Overview
Mechanical devices for creating knitted fabric faster and more consistently than hand knitting.

## Available Equipment

We have two respectable knitting machines in their best years.

- Brother Profile 550 (1950s)
- Brother KH-260 (1980s pattern punch cards)

## What You Can Make
- Sweaters and garments
- Scarves and accessories
- Blankets
- Swatches for patterns
- Custom fabric

## Safety Guidelines
- Keep fingers clear of moving needles
- Watch for yarn tangles
- Secure yarn supply to prevent pulling
- Clean lint regularly (fire hazard)
- Follow threading instructions carefully

## Getting Started
1. Choose appropriate yarn for machine gauge
2. Set up yarn feeder
3. Cast on stitches
4. Follow pattern or create custom design
5. Monitor for dropped stitches
6. Bind off when complete

## Maintenance
- Clean lint from needles regularly
- Oil according to schedule
- Check for bent or damaged needles
- Store with dust cover
- Report any issues to workshop staff

## Troubleshooting
- **Dropped stitches**: Rehook with latch tool, check tension
- **Uneven tension**: Adjust yarn feeder, check yarn path
- **Jammed carriage**: Clear obstruction, check for bent needles
- **Skipped needles**: Check needle positions, verify pattern
